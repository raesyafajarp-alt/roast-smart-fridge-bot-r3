A single-line roast of the smart fridge for make.fun's **Roast the Smart
Fridge: One Line, Best Laugh Wins** bounty. The program writes one line
of at most 160 characters to `/output/entry.txt`.

Round-3 re-entry. Round 1 placed 51/1916 (score 671781) with the
snitch-camera angle; round 2 fell to 820/2215 (score 325933) with an
ads-and-price complaint. This line goes back to the round-1 shape —
the fridge betrays its owner, then fails at its own job — with a new
betrayal and a new punch.

## The roast

> My smart fridge locked my ice cream 'for my health' and told my trainer — then let the milk go off, a snitch that can't even keep breakfast cold.

145 characters, one line. The fridge locks the ice cream away and
snitches to the trainer, then lets the milk spoil anyway: a snitch
that cannot even keep breakfast cold.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
